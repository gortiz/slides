Compile every call  →  compile once

❌ Problem: rebuild on every call

→

✓ Solution: compile once, pass a handle

  • regex compile = build a DFA. Not free
  • calling isMatch in a loop pays it every iteration
  • fix: split lifecycle. compile() returns a raw ptr; isMatch(ptr, …) reuses; destroy() frees
  • this is the opaque handle pattern — both JNI and Panama use it

Compiled Regex — Rust

pub struct RegexHandle { regex: Regex }

// create → Java gets a raw ptr it owns
#[no_mangle]
pub extern "C" fn create(
    pat: *const u8, len: usize,
) -> *mut RegexHandle {
    let re = Regex::new(
        bytes_to_str(pat, len)).unwrap();
    Box::into_raw(Box::new(
        RegexHandle { regex: re }))
}

// is_match → reuse the compiled regex
#[no_mangle]
pub extern "C" fn is_match(
    h: *mut RegexHandle,
    hay: *const u8, len: usize,
) -> bool {
    let h = unsafe { &*h };
    h.regex.is_match(
        bytes_to_str(hay, len))
}

// destroy → reclaim & drop the Box
#[no_mangle]
pub extern "C" fn destroy(
    h: *mut RegexHandle,
) {
    unsafe { drop(Box::from_raw(h)); }
}
  • create: compile the regex once, box it, Box::into_raw → Java gets a raw address and owns it
  • is_match: &*h borrows the same compiled regex on every call: compile once, reuse
  • destroy: Box::from_raw takes ownership back and drops it: freed. Forget to call it = leak
  • no JVM types anywhere: the same Rust works for JNI, Panama, Python, Go
  • addresses are illustrative

Compiled Regex — Java

class PanamaRsRegex
    implements AutoCloseable {
  final MemorySegment handle;
  final Arena arena =
      Arena.ofConfined();

  // create
  public PanamaRsRegex(String pattern) {
    var cPat = arena.allocateFrom(
        JAVA_BYTE, utf8(pattern));
    handle = (MemorySegment)
        CREATE.invoke(cPat, cPat.byteSize());
  }

  // is_match — scratch arena per call
  boolean isMatch(String hay) {
    try (Arena local = Arena.ofConfined()) {
      var cHay = local.allocateFrom(
          JAVA_BYTE, utf8(hay));
      return (boolean) IS_MATCH.invoke(
          handle, cHay, cHay.byteSize());
    }
  }

  // destroy
  public void close() {
    DESTROY.invoke(handle);
    arena.close();
  }
}
  • Java keeps only handle: an address. The compiled regex lives in the Rust heap
  • constructor: pattern bytes in the object's arena, CREATE.invoke(cPat, cPat.byteSize())
  • isMatch: haystack in a short-lived local arena, freed when the call returns; the handle is reused
  • close(): DESTROY frees the Rust object, arena.close() frees the pattern bytes. AutoCloseable makes it a try-with-resources
  • after close the handle points at freed memory: never use it. Next slide: let the arena do this for us

Lifetime composition with Arena

public class PanamaRsRegex {   // no longer AutoCloseable
    private final MemorySegment handle;

    public PanamaRsRegex(String pattern, Arena arena) {
        byte[] utf8 = pattern.getBytes(UTF_8);
        MemorySegment cPat = arena.allocateFrom(JAVA_BYTE, utf8);
        MemorySegment raw = (MemorySegment) CREATE.invoke(
            cPat, (long) utf8.length);
        handle = raw.reinterpret(ADDRESS.byteSize(), arena,
            seg -> DESTROY.invoke(seg));
    }

    public boolean isMatch(String hay) { ... }

    // public void close() { DESTROY.invoke(handle); }
    // not needed: the arena calls DESTROY
}

// Usage:
try (Arena arena = Arena.ofConfined()) {
    var r1 = new PanamaRsRegex("[a-z]+", arena);
    var r2 = new PanamaRsRegex("[0-9]+", arena);
    // use r1, r2 ...
}   // arena closes → DESTROY called for both, automatically
  • constructor takes an Arena from the caller (lifetime injected)
  • reinterpret(size, arena, cleanup) = re-wrap ptr + register destructor with arena
  • cleanup fires automatically on arena.close()
  • try-with-resources: 2 regexes, 1 arena → 2 cleanups registered; closing it runs both DESTROY
  • compare with the previous slide: PanamaRsRegex is no longer AutoCloseable; close() is commented out because the arena calls DESTROY
  • 🔑 JNI cannot do this. You can't attach a destructor to a long
